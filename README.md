# EduKSX-Suite

Verteilpaket für das Selbst-Hosting der EduKSX-Module: Installer mit einem Befehl, VM-Vorlage, Compose-Grundgerüst, Update-Dienst und Sicherung, damit eine Schule oder Gemeinde die Module ohne Docker-Kenntnisse auf einem eigenen Server betreibt.

## Stand

Projektstart, noch kein lauffähiges Paket. Erster Meilenstein «2026.11.0 – Probe» (#2–#8): Compose-Grundgerüst,
Installer, Update-Dienst, Sicherung, VM-Vorlage, CI-Probe und Anleitung. Grundlage ist das Konzept
[Selbst-Hosting](https://github.com/MarkusKeller8200/EduKSX-Architektur/blob/main/docs/KONZEPT-SELBSTHOSTING.md)
in EduKSX-Architektur (privat) – Steckbrief: [docs/PROJEKTSTART.md](docs/PROJEKTSTART.md).
